# 品牌产品视觉策划方法论

## 诊断链路

| 层级 | 核心问题 | 关键产出 |
|---|---|---|
| 商业 | 增长目标、利润和资源约束是什么 | 目标与边界 |
| 市场 | 品类如何增长、竞争如何分化 | 机会地图 |
| 人群 | 谁在何种场景下为何购买 | JTBD、阻力与触发 |
| 产品 | 能提供何种独特且可信的价值 | 产品角色与证据链 |
| 品牌 | 应占据何种心智位置 | 定位与价值主张 |
| 视觉 | 哪种感知能强化定位 | 设计命题与系统 |
| 渠道 | 不同触点怎样完成转化 | 信息架构与规范 |

定位公式：面向【核心人群】在【关键场景】中的【高优先需求】，品牌以【品类/角色】提供【核心价值】，因为【可信证据】，区别于【替代方案】。

## 产品策划

建立“用户任务—需求—利益—功能—证据—表达”链。产品组合按实际需要设置引流款、主销款、利润款、形象款或复购款，不强行凑齐。每个卖点都要连接配方、工艺、结构、服务、检测、数据或体验机制等证据。

## 视觉定位

先写设计命题：“用【感知特征】把【品牌价值】转化为【目标人群可识别的体验】，同时避开【品类陈词滥调】。”

再定义识别资产、色彩、字体、图形、摄影、版式、包装和电商系统。每个方向同时给关键词、反关键词、设计原理、应用示例与失败边界。

## 营销转化

按“看见—理解—相信—行动—复购”设计符号钩子、价值表达、信任证据、商品机制、CTA、会员与内容服务。内容支柱控制在3—5个，每个写清人群、命题、证据、形式、平台和指标。

## 方案评分

按1—5分评价：商业适配20%、人群相关15%、竞争差异15%、产品可信15%、视觉识别与延展15%、渠道转化10%、成本落地10%。低于3分必须提出修正动作。

## PPT叙事

推荐顺序：为什么现在做 → 真正问题 → 机会 → 选择 → 赢的理由 → 视觉表达 → 触点落地 → 实施验证。每页标题必须是结论句，不能只写“市场分析”“视觉方向”。

## 质量红线

- 无来源数据、伪造访谈、虚构背书或绝对化功效。
- 用“高级、年轻、国际化”等空词代替可观察的设计规范。
- 策略、人群、产品与视觉没有因果关系。
- 只给灵感图，不给规则、应用与成本边界。
- 忽视商标、广告法、字体/图片授权、包装标识或平台规范。
